## 一个值得注意的现象

compressed 图中，被 skip 的 thought 后续仍会进入 score 节点，但 score 给 `[SKIP]` 节点打了较差分数：

```
op10 score 中 skip 节点分数为 300
正常节点分数为 0
```

最终 `keep_best_n` 保留的是分数 0 的正常正确 thought，没有选择 `[SKIP]`。这说明当前流程下 `[SKIP]` 占位节点没有污染最终答案选择

## doc_merge 100 条数据并行运行

```bash

```

如果确认 doc_merge 数据集就是 0-99，也可以省略 `--data-ids`，脚本会自动读取该任务全部样例：

```bash
python examples/parallel_batch_static_skip_experiment.py --model-name deepseek-v4-flash --tasks doc_merge --shard-size 20 --max-workers 5 --skip-ratio 0.2 --skip-orders low high --entropy-field normalized_avg_entropy_bits
```
